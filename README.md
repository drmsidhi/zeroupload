# ⚡ ZeroUpload

> Simple, fast, and privacy-friendly in-browser tools for resizing, compressing, and converting images, signatures, and documents.

ZeroUpload processes everything **100% on the client-side** using standard browser Canvas APIs. No images or documents are ever uploaded to any remote server, making it safe for confidential IDs, official forms, and signatures.

---

## ✨ Features

- **Zero Server Uploads:** All operations run locally inside your browser memory.
- **Fast Resizing & Scaling:** Precise width/height adjustments with aspect-ratio locking.
- **Form-Ready Presets:** Quick dimension adjustments for standard signatures and passport photos.
- **Dynamic Compression:** Real-time file size preview with custom quality thresholds.
- **Format Conversion:** Convert between JPEG, PNG, and WebP instantly.
